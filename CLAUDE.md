# CLAUDE.md — CP_RAG

RAG chat app over Primary Care SG chronic-care care protocols + MOH public health guidance (Phase 2). FastAPI serves a single-page UI (`static/index.html`); `rag.py` scrapes the source sites (`SOURCES`), embeds chunks into a persisted Chroma store, and answers via `deepseek/deepseek-v4-flash-0731` (paid, fast) routed through **OpenRouter** (OpenAI-compatible gateway; provider + models are env-configured, see `.env.example`) — the UI header toggle can flip the CHAT path to a local vLLM server (`LOCAL_*` env, `POST /api/provider`); embeddings are never switched. The RAG prompt has five labelled sections — *Protocol content* / *Clinical guidelines* / *Public health guidance* / *Community resources* (NTUC Active Ageing calendars, non-clinical) / *Local context* (live snapshot, provenance rules in `docs/signal-research.md` §12–13, §17).

## Golden rules (do not violate)

- **OpenAI credits are a budget, not infinite.** The account has hit 429 `credit_balance_exhausted` before. Every `/api/chat` costs an embedding call + a chat-model call; `POST /api/ingest` re-embeds the *entire* corpus (fresh-directory use only); `POST /api/ingest/append` is the cheap path — it skips sites already in the store (host-level) and embeds only new sources, with a 500-chunk refusal cap (OpenRouter's 300k-token/request limit). Keep test API calls to the bare minimum — prefer `/api/status` (free) over chat probes, and never loop or retry against the API. The clinician brief (`POST /api/brief/generate`) is the only other LLM path: one generate = 1 chat-model call (≤2 provider round-trips), 0 embeddings, 0 retrieval, 15-min success cache, 60-s force-regenerate cooldown (429), 90-s failure sentinel (502); `GET /api/brief` is free and never builds. The community-calendar refresh (`POST /api/community/refresh`) is embedding-only (~500 ada-002 chunks ≈ $0.01, never re-embeds the rest of the corpus; 409 in flight, 60 s cooldown after a success; fails fast with the store untouched on a structural failure).
- **Secrets live in `.env` only** (gitignored). Never print a full key, never commit it, and keep `.env.example` in sync with the variables the code reads. `.env` is machine-parsed: exactly one `KEY=value` per line, no commentary — a stray pasted line breaks the parse with warnings on every import.
- **`chroma_db/` is a persisted artifact, not source.** It is gitignored and is expensive to rebuild (full scrape + full re-embed). Don't delete it casually, don't commit it, and don't re-ingest "just to test". If the app returns 503 "Knowledge base not ready", check that `chroma_db/` exists before touching ingest.
- **Python 3.9 only** (system `/usr/bin/python3`). No 3.10+ syntax. The venv lives in the repo root; if this folder ever moves, the venv's shebangs break silently — recreate it (`python3 -m venv venv && venv/bin/python -m pip install -r requirements.txt`) rather than patching it.
- **The scrape target is a live external site** (`SOURCE_URL` in `rag.py`). If the site changes, ingest can silently return junk or zero chunks — always check the `chunks` count in the `/api/ingest` response before trusting the result.

## Stack (decided — don't re-litigate)

- **LangChain 0.3.x** (`langchain-community`, `langchain-openai`) — chain: retriever (k=12 since Phase 5's guideline corpus) + `ChatPromptTemplate` + chat model (env `CHAT_MODEL`, currently `deepseek/deepseek-v4-flash-0731` via OpenRouter, temperature 0). Chat-model provider is switchable at runtime (UI header toggle → `POST /api/provider`): `openrouter` vs `local` vLLM (`LOCAL_BASE_URL`/`LOCAL_CHAT_MODEL`/`LOCAL_API_KEY`); the chain builds the LLM per invoke so a switch needs no restart.

Phase 6: three hash-routed tabs — `#/brief` (default, clinician dashboard: 6 KPI tiles (Nearest polyclinic tile removed 2026-09-10 — static, no signal; data kept in prompt + raw context; Phase 9 2026-09-10: planning tile renamed **`New health facilities (3 mo)`** with the near band at **2 km**, and a new **`Active Ageing (2 km)`** tile + "Active Ageing (NTUC Health, island-wide)" raw-context card with per-centre calendar PDF links) + generated brief + Protocol spotlight rendered only from structured `protocol_links.active`), `#/chat`, `#/library` (corpus inventory; the PDF upload bar lives here). The context strip survives in the Brief view as the collapsed "Raw context data" drill-down — its DOM nodes are never removed, the 15-min refresh intervals depend on them.
- **Context layer** (Phases 0–4, done): `context/` package (stdlib-only) builds a live population-level snapshot from key-free data.gov.sg feeds; `context/widb.py` (Phase 3) fetches the newest CDA Weekly Infectious Diseases Bulletin PDF (archive crawl → newest-to-oldest walk-back → `pypdf` table/narrative parse, 3-day disk cache) and adds the `disease_week` block (national dengue/influenza/ARI/HFMD counts) to the snapshot; `context/ura.py` (Phase 4/8, needs `URA_ACCESS_KEY` in .env) fetches the URA daily token + `Planning_Decision` rows (90-day `last_dnload_date` window) and filters healthcare-related written permissions into the `catchment_change` block (island-wide; ## Conventions

- All config via env; `.env.example` stays current. No secrets in code or logs.
- Keep endpoints small. Long blocking work (the LLM call in `/api/chat`, the ingest crawls) runs in a thread-pool executor — never call blocking chain/ingest code directly in an `async def` endpoint, or the event loop freezes and the whole server stops responding (no background jobs needed yet).
- No test suite exists. The standing check is: server boots, `/api/status` returns `{"ready": true}`, and `/` serves 200.

## Commands (keep these working)

- `venv/bin/uvicorn app:app --port 5001` (or `python app.py`, same default) — run the app, then open http://localhost:5001
- `curl -s localhost:5001/api/status` — free readiness check (run this, not chat, when verifying a change)
- `curl -s localhost:5001/api/provider` — active chat-model provider (free); switch with `curl -X POST -H 'Content-Type: application/json' -d '{"provider":"local"}' localhost:5001/api/provider` (free, config-only — no connectivity probe, embeddings unaffected)
- `curl -s localhost:5001/api/context` — live snapshot (15-min cache; first hit builds, ~15–40 s, key-free)
- `curl -s localhost:5001/api/brief` — free brief status/cache (never builds; `status` is fresh/stale/none)
- `curl -X POST "localhost:5001/api/brief/generate"` — generate the clinician brief (**costs 1 chat-model call** — the only LLM path outside `/api/chat`; 429 if force within 60 s of the last generation)
- `curl -s localhost:5001/api/library` — free corpus inventory (PDFs + web sources by site + community calendars + totals)
- `curl -X POST localhost:5001/api/community/refresh` — monthly refresh of the NTUC community calendars (replaces last month's chunks; ~500 ada-002 embeds ≈ $0.01; 409 in flight, 429 within 60 s of the last success; 502 "store untouched" on structural failure)
- `curl -X POST localhost:5001/api/ingest` — rebuild the knowledge base (**costs API credits; fresh directories only**)
- `curl -X POST localhost:5001/api/ingest/append` — append-only ingest: embeds only sources not in the store (host-level skip + 500-chunk cap); cheap and idempotent
- `venv/bin/python -m pip install -r requirements.txt` — (re)install deps
